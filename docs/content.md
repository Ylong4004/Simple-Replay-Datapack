# Simple Replay：数据包玩家回放系统

> 摘要：Simple Replay 是一个面向 Minecraft Java 26.1.2 至 26.2 的纯数据包玩家回放系统。它会记录玩家的位置、视角、姿态、装备、挥手等状态，再由 `minecraft:mannequin` 玩家模型或其他实体在游戏内重演，适合剧情演出、路线展示、教学演示和多人动作编排。

## 1. 功能概览

- **单人录制**：记录一名玩家的动作，支持暂停、继续和保存。
- **多人同步录制**：最多 8 名成员共同录制，由主持人统一控制。
- **自定义演员**：修改回放实体、玩家皮肤、显示名等外观信息，也可单独编辑多人录像中的每名演员。
- **录像管理**：通过游戏内对话框和可点击列表编辑录像、切换循环播放、设置结束回调；支持多段录像同时播放。

系统保存的是玩家动作数据，不是视频，也不记录整个世界的变化。

## 2. 安装与准备

1. 将数据包文件夹或压缩包放入世界的 `datapacks` 目录，确保根目录直接包含 `pack.mcmeta` 和 `data`。
2. 进入世界后执行 `/reload`，再用 `/datapack list enabled` 确认已启用。
3. 执行以下命令查看游戏内中文帮助：

```mcfunction
/function replay:help
```

目标版本为 **Minecraft Java 26.1.2 至 26.2**，当前主要在 26.2 环境中开发和验证。安装或更新前建议备份世界和已有录像。

创建录制、播放和管理录像需要执行 `/function` 的权限；普通玩家可以用 `/trigger replay.join` 加入多人录制。录像库和设置由整个世界共用，同一时间只允许一个录制会话，准备中的录制也会占用这个名额。

## 3. 录制与保存

### 单人录制

先清空快捷栏第 7 至 9 格，再执行：

```mcfunction
/function replay:record/start
```

这时只会进入准备状态。手持第 7 格的“开始录制”物品右键，才会正式记录动作。

| 快捷栏位置              | 操作                                         |
| ----------------------- | -------------------------------------------- |
| 第 7 格（`hotbar.6`） | 右键开始、暂停或继续录制                     |
| 第 8 格（`hotbar.7`） | 右键结束并打开保存对话框；尚未开始时用于取消 |
| 第 9 格（`hotbar.8`） | 手持“挥手标记”右键或攻击，手动记录挥手     |

录制过程中会显示当前录制时间。方块交互、放置方块、攻击实体或玩家也会记录为挥手动作，但回放时不会重新放置或破坏方块。

### 多人同步录制

主持人清空快捷栏第 7 至 9 格后执行：

```mcfunction
/function replay:multi/create
```

其他参与者清空快捷栏第 9 格，在正式开始前执行：

```mcfunction
/trigger replay.join
```

最多支持 **8 人，包含主持人**，开始后不能中途加入。成员到齐后，主持人用控制物品统一开始、暂停、继续和结束录制；参与者需保持在线。

保存后，每名成员默认使用自己的玩家模型资料。需要换皮肤或改成其他实体时，可以在录像库的“成员”页面分别编辑。

### 保存录像

结束录制会打开保存对话框，可填写录像名、录制者、描述、默认演员外观、是否循环播放，以及播放结束后执行的函数 ID。

录像名最长 **64 个字符**，只能使用英文字母、数字、下划线、连字符、加号和点，例如 `Replay_01`。自定义纹理需要配套资源包；直接使用玩家皮肤时可填写玩家模型的 profile 名称。

多人录像保存的是整段录像的信息；修改个别成员的外观，请在保存后进入“成员”页面操作。

## 4. 播放与管理

### 播放录像

单人和多人录像使用同一个命令，把 `Replay` 换成已保存的录像名即可：

```mcfunction
/function replay:play/start {name:"Replay"}
```

默认使用录像保存的演员外观和播放选项。多人录像会为每名成员生成独立演员，同步播放各自的动作。

由玩家执行播放命令时，会获得“暂停/继续播放”和“结束播放”控制物品。让准心靠近目标演员，再手持对应物品右键即可控制。

也可以直接用命令停止：

```mcfunction
/function replay:play/stop_nearest
/function replay:play/stop
```

第一条停止当前维度内最近的一名演员，第二条停止全部回放。是否移除数据包生成的演员，可在设置中调整。

### 临时更换演员

如果只想为本次播放换一个演员，并沿用录像保存的循环和结束回调设置，可以执行：

```mcfunction
/function replay:play/start_profile_default {name:"Replay",entity:{entity_type:"minecraft:mannequin",profile_name:"PlayerName",custom_name:"回放演员"}}
```

将 `PlayerName` 换成想使用的玩家名。也可更换 `entity_type`，但其他实体不一定能完整表现玩家的姿态、装备或皮肤效果。

### 录像库与设置

打开录像库：

```mcfunction
/function replay:library/list
```

列表会显示录像时长、录制者、类型和演员数量，并提供“播放 / 编辑 / 成员 / 覆盖 / 循环 / 删除”按钮。多人录像的整体编辑中，“统一应用演员数据到全部成员”默认关闭，需要批量更换演员时再勾选。

打开设置：

```mcfunction
/function replay:settings/open
```

可以调整播放速度、播放进度显示、录制时长上限、演员清理方式，以及控制物品的选择半径和选中发光效果。默认会在播放同名录像前清理上一次由它生成的演员；需要同一录像同时出现多份时，可关闭这个选项。

## 6. 使用限制与卸载

- 当前支持原版主世界、下界和末地，自定义维度需要额外适配。
- 回放演员所在区块必须保持加载，否则播放会暂停。
- 不记录方块变化、容器内容、聊天、音效、粒子或其他世界实体的变化。
- 非玩家模型实体的表现取决于实体本身；例如敌对生物在和平难度下可能无法创建。

需要卸载时，先执行以下命令清理运行环境，已保存录像会保留：

```mcfunction
/function replay:uninstall
```

若要连录像库一起删除，使用 `/function replay:uninstall_all`，此操作不可撤销。清理只影响在线玩家和已加载区块中的实体；执行后应禁用或移除数据包，避免再次 `/reload` 时重新安装。
